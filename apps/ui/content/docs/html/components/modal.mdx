title: Modal
description: Modals interrupt the flow with focused content that requires user attention.
---

Modals are floating dialogs that block the rest of the UI until dismissed. The base markup nests `modal-dialog` and `modal-content` inside a `modal` overlay; the examples below render the modal in its open state for documentation.

<ModalClassesTable />

## Default

The default modal stacks header, body and footer with consistent spacing.

<HtmlPreview name="modal-default" />

## Sizes

Use `modal-dialog-sm`, `modal-dialog-md`, `modal-dialog-lg` or `modal-dialog-xl` to control width.

<HtmlPreview name="modal-sizes" />

## Positions

Combine `modal-top`, `modal-middle` (default) or `modal-bottom` with the `-start` / `-end` modifiers to align the dialog inside the viewport.

<HtmlPreview name="modal-positions" />

## With Form

Use the `modal-body` for form fields and the `modal-footer` for primary actions.
