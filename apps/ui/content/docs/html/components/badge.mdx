Badges highlight short pieces of information like counts, statuses, or tags. They support semantic colors, sizes, and soft or outline variants.

<BadgeClassesTable />

## Default Badge

The base badge only requires the `badge` class.

<HtmlPreview name="badge-default" />

## Badge Sizes

Control the size using `badge-xs`, `badge-sm`, `badge-md` (default), `badge-lg`, or `badge-xl`.

<HtmlPreview name="badge-sizes" />

## Badge Colors

Apply semantic colors using `badge-primary`, `badge-secondary`, `badge-accent`, `badge-info`, `badge-success`, `badge-warning`, or `badge-error`.

<HtmlPreview name="badge-colors" />

## Soft Badges

Use `badge-soft` for a subtle, low-emphasis badge with tinted background.

<HtmlPreview name="badge-soft" />

## Outline Badges

Use `badge-outline` for transparent badges with a colored border.

<HtmlPreview name="badge-outline" />
