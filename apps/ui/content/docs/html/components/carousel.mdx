title: Carousel

---

Carousels display multiple slides in a horizontally scrolling container. The base markup provides the layout while a JS plugin handles the actual sliding.

<CarouselClassesTable />

## Default

A carousel needs `carousel` on the wrapper, `carousel-body` for the track and `carousel-slide` for each item.

<HtmlPreview name="carousel-default" />

## With Arrows

Add `carousel-prev` and `carousel-next` buttons to navigate between slides.

<HtmlPreview name="carousel-arrows" />

## With Dots

Use `carousel-dot` indicators to jump to a specific slide.

<HtmlPreview name="carousel-dots" />

## With Bars

Use `carousel-box` for bar-shaped indicators when you want a more linear feel.
