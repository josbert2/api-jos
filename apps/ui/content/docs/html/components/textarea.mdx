Textareas let users enter multi-line text. They support sizes, validation states, floating labels, and disabled state.

<TextareaClassesTable />

## Default Textarea

The base textarea only requires the `textarea` class on a `<textarea>` element.

<HtmlPreview name="textarea-default" />

## Textarea Sizes

Control the size using `textarea-xs`, `textarea-sm`, `textarea-md` (default), `textarea-lg`, or `textarea-xl`.

<HtmlPreview name="textarea-sizes" />

## Textarea States

Use `is-valid` or `is-invalid` to communicate validation status. Disable a textarea with the native `disabled` attribute.

<HtmlPreview name="textarea-states" />

## Floating Label

Wrap the textarea in `.textarea-floating` and add a `.textarea-floating-label` for an animated label.

<HtmlPreview name="textarea-floating" />

## Disabled Textarea

Use the native `disabled` attribute to indicate the textarea cannot be edited.

<HtmlPreview name="textarea-disabled" />
