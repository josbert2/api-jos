title: Navbar
description: Navbars anchor primary navigation at the top of a page.
---

Navbars provide a horizontal layout with `navbar-start`, `navbar-center` and `navbar-end` regions. Each region behaves as a flex container so you can nest buttons, menus, inputs or avatars freely.
