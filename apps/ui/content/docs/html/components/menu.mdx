---
title: Menu
description: Menus list links or actions vertically or horizontally.
---

Menus render lists of navigational items with consistent spacing, hover and active states. Use `menu-active` to mark the current item, `menu-disabled` to disable one and `menu-title` for section headers.

<MenuClassesTable />

## Default

The minimal menu is an unordered list with the `menu` class.

<HtmlPreview name="menu-default" />

## Sizes

Use `menu-xs`, `menu-sm`, `menu-md` (default), `menu-lg` or `menu-xl` to scale the menu.

<HtmlPreview name="menu-sizes" />

## With Icons

Combine icons and badges inside menu items for richer navigation.

<HtmlPreview name="menu-icons" />

## With Titles

Group items with `menu-title` and use `menu-disabled` for inactive entries.

<HtmlPreview name="menu-titled" />

## Horizontal

Use `menu-horizontal` to render the items inline, useful for navbars.
