Checkboxes let users select one or more options from a list. They support sizes, semantic colors, indeterminate and disabled states.

<CheckboxClassesTable />

## Default Checkbox

The base checkbox only requires the `checkbox` class on an `<input type="checkbox">`.

<HtmlPreview name="checkbox-default" />

## Checkbox Sizes

Control the size using `checkbox-xs`, `checkbox-sm`, `checkbox-md` (default), `checkbox-lg`, or `checkbox-xl`.

<HtmlPreview name="checkbox-sizes" />

## Checkbox Colors

Apply semantic colors using `checkbox-primary`, `checkbox-secondary`, `checkbox-accent`, `checkbox-info`, `checkbox-success`, `checkbox-warning`, or `checkbox-error`.

<HtmlPreview name="checkbox-colors" />

## Checkbox with Label

Wrap a checkbox and a `.label-text` inside a `<label>` to make the label clickable.

<HtmlPreview name="checkbox-label" />

## Disabled Checkbox

Use the native `disabled` attribute to indicate the checkbox cannot be toggled.

<HtmlPreview name="checkbox-disabled" />
