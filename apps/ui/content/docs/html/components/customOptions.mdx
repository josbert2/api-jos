Custom options turn radio or checkbox cards into rich selectable blocks. They highlight the selected card and support a soft tinted variant.

<CustomOptionsClassesTable />

## Default Custom Option

Wrap the input and label inside a `<label class="custom-option">`. The card highlights when its inner control is checked.

## Soft Custom Option

Use `.custom-soft-option` for a subtle tinted background.
