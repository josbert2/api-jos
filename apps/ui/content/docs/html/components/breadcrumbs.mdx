Breadcrumbs help users navigate through a hierarchy of pages. They render as an ordered list with separators between items.

<BreadcrumbsClassesTable />

## Default Breadcrumbs

Wrap an `<ol>` in a `nav.breadcrumbs` element. Use `breadcrumbs-separator` for the dividers.
