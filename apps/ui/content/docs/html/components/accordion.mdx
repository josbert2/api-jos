Accordions group related content into vertically stacked, expandable panels. They support bordered and shadowed variants and use the `active` class to mark the open item.

<AccordionClassesTable />

## Default

The base accordion uses `accordion` on the wrapper and `accordion-item` on each panel. Add `active` to the item that should start expanded.

<HtmlPreview name="accordion-default" />

## Bordered

Use `accordion-bordered` for a single outer border with dividers between items.

<HtmlPreview name="accordion-bordered" />

## Shadow

Use `accordion-shadow` to render each item as its own elevated card.

<HtmlPreview name="accordion-shadow" />

## With Icon

Place icons inside the toggle to communicate the topic at a glance.

<HtmlPreview name="accordion-icon" />

## Disabled

Add the native `disabled` attribute to an `accordion-toggle` to prevent it from opening.
