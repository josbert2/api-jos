Avatars represent users with images, initials, or status indicators. They support sizes, shapes, presence dots, and grouping.

<AvatarClassesTable />

## Default Avatar

The base avatar wraps an image inside a sized `<div>`. Add `rounded-full` for a circular avatar.

<HtmlPreview name="avatar-default" />

## Avatar Sizes

Control the size by changing the wrapper width (`w-8`, `w-12`, `w-16`, `w-24`).

<HtmlPreview name="avatar-sizes" />

## Avatar Shapes

Combine with `rounded-full`, `rounded-2xl`, or `rounded` for different shapes.

<HtmlPreview name="avatar-shapes" />

## Avatar Placeholder

Use `avatar-placeholder` to render initials or a fallback when no image is available.

<HtmlPreview name="avatar-placeholder" />

## Avatar with Status

Add `avatar-online-bottom`, `avatar-offline-bottom`, `avatar-busy-bottom`, or `avatar-away-bottom` to show presence.

<HtmlPreview name="avatar-status" />

## Avatar Group

Wrap multiple avatars in `avatar-group` with negative spacing for an overlapping list.

<HtmlPreview name="avatar-group" />
