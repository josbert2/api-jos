---
title: Mockup
description: Mockups frame content inside code, window, browser or phone chrome.
---

Mockups wrap arbitrary content inside a stylized device or app chrome. They are useful for marketing pages, screenshots and onboarding tours.

<MockupClassesTable />

## Code

`mockup-code` renders a terminal-like block. Use `data-prefix` on each line to set the gutter symbol.

<HtmlPreview name="mockup-code" />

## Window

`mockup-window` adds the classic three-dots window header.

<HtmlPreview name="mockup-window" />

## Browser

`mockup-browser` adds a URL bar via `mockup-browser-toolbar` and an `input` element.

<HtmlPreview name="mockup-browser" />

## Phone

`mockup-phone` frames content inside a phone bezel using `mockup-phone-camera` and `mockup-phone-display`.
