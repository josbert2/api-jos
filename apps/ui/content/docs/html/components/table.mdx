title: Table
description: Tables present tabular data with consistent spacing and dividers.
---

Tables render rows of data with sensible defaults for typography, padding and dividers. Use `table-striped` for zebra rows, `row-hover` per row for hover states, and size modifiers to scale density.

<TableClassesTable />

## Default

The base table just needs the `table` class on the `<table>` element.

<HtmlPreview name="table-default" />

## Striped

Use `table-striped` to alternate the row background.

<HtmlPreview name="table-striped" />

## Sizes

Use `table-xs`, `table-sm`, `table-md` (default), `table-lg` or `table-xl` to control density.

<HtmlPreview name="table-sizes" />

## Hover and Active Rows

Use `row-hover` for hover highlighting and `row-active` to mark a selected row.

<HtmlPreview name="table-hover" />

## Borderless

Use `table-borderless` for a minimal look without dividers.

<HtmlPreview name="table-borderless" />
