Ranges let users pick a numeric value within a min/max bound. They support sizes, semantic colors, and disabled state.

<RangeClassesTable />

## Default Range

The base range only requires the `range` class on an `<input type="range">`.

<HtmlPreview name="range-default" />

## Range Sizes

Control the size using `range-xs`, `range-sm`, `range-md` (default), `range-lg`, or `range-xl`.

<HtmlPreview name="range-sizes" />

## Range Colors

Apply semantic colors using `range-primary`, `range-secondary`, `range-accent`, `range-info`, `range-success`, `range-warning`, or `range-error`.

<HtmlPreview name="range-colors" />

## Range with Steps

Use the `step` attribute to constrain the value to discrete increments.

<HtmlPreview name="range-steps" />

## Disabled Range

Use the native `disabled` attribute to indicate the range cannot be adjusted.

<HtmlPreview name="range-disabled" />
