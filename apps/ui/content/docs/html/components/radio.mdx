Radios let users choose a single option from a set. They support sizes, semantic colors, an inset variant, and disabled state.

<RadioClassesTable />

## Default Radio

The base radio only requires the `radio` class on an `<input type="radio">`.

<HtmlPreview name="radio-default" />

## Radio Sizes

Control the size using `radio-xs`, `radio-sm`, `radio-md` (default), `radio-lg`, or `radio-xl`.

<HtmlPreview name="radio-sizes" />

## Radio Colors

Apply semantic colors using `radio-primary`, `radio-secondary`, `radio-accent`, `radio-info`, `radio-success`, `radio-warning`, or `radio-error`.

<HtmlPreview name="radio-colors" />

## Inset Radio

Use `radio-inset` for a filled inset style on the selected state.

<HtmlPreview name="radio-inset" />

## Radio Group

Wrap radios with a shared `name` attribute to form a single group.

<HtmlPreview name="radio-group" />

## Disabled Radio

Use the native `disabled` attribute to indicate the radio cannot be selected.

<HtmlPreview name="radio-disabled" />
