Display the completion progress of a task. The progress component supports semantic colors, striped patterns, vertical orientation, and indeterminate states.

<ProgressClassesTable />

## Default Progress

Wrap a `progress-bar` inside a `progress` container. Set the inline `width` to the current value.

<HtmlPreview name="progress-default" />

## Progress Colors

Apply semantic colors with `progress-primary`, `progress-info`, `progress-success`, `progress-warning`, or `progress-error` on the inner bar.

<HtmlPreview name="progress-colors" />

## Striped Progress

Use `progress-striped` for diagonal stripes, and add `progress-animated` to make them slide.

<HtmlPreview name="progress-striped" />

## Indeterminate Progress

Use `progress-indeterminate` and set `--progress-color` for an animated, value-less progress bar.

<HtmlPreview name="progress-indeterminate" />

## Vertical Progress

Use `progress-vertical` for vertical bars. Drive the fill with inline `height` instead of `width`.

<HtmlPreview name="progress-vertical" />
