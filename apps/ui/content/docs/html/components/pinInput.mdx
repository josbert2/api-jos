Pin inputs let users enter short numeric codes one digit at a time. They support sizes, an underline variant, and disabled state.

<PinInputClassesTable />

## Default Pin Input

The base pin input uses the `pin-input` class on each individual `<input>` element.

<HtmlPreview name="pinInput-default" />

## Pin Input Sizes

Control the size using `pin-input-xs`, `pin-input-sm`, `pin-input-md` (default), `pin-input-lg`, or `pin-input-xl`.

<HtmlPreview name="pinInput-sizes" />

## Underline Variant

Use `pin-input-underline` for a minimal style with only a bottom border.

<HtmlPreview name="pinInput-underline" />

## Disabled Pin Input

Use the native `disabled` attribute to prevent input.
