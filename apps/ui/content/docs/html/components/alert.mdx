Alerts inform users about important events or system status. They support semantic colors, soft and outline variants, icons, titles and inline actions.

<AlertClassesTable />

## Default Alert

The base alert only requires the `alert` class. Use the `role="alert"` attribute for accessibility.

<HtmlPreview name="alert-default" />

## Alert Colors

Apply semantic colors using `alert-primary`, `alert-info`, `alert-success`, `alert-warning`, or `alert-error`.

<HtmlPreview name="alert-colors" />

## Soft Alerts

Use `alert-soft` for a subtle, low-emphasis alert. Combine with color classes for tinted backgrounds.

<HtmlPreview name="alert-soft" />

## Outline Alerts

Use `alert-outline` for transparent alerts with visible borders.

<HtmlPreview name="alert-outline" />

## Alert with Icon

Add an SVG icon as the first child to communicate severity at a glance.
