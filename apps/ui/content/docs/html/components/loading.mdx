## Default Loading

The base `loading` class renders the default spinner animation.

## Loading Styles

Pick a visual style with `loading-spinner`, `loading-dots`, `loading-ring`, `loading-ball`, `loading-bars`, or `loading-infinity`.

<HtmlPreview name="loading-styles" />

## Loading Sizes

Control the size using `loading-xs`, `loading-sm`, `loading-md` (default), `loading-lg`, or `loading-xl`.

<HtmlPreview name="loading-sizes" />

## Loading Colors

Loading inherits `currentColor`, so combine with text utilities like `text-primary`, `text-success`, etc.
