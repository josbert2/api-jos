---
title: Tab
description: Tabs let users switch between related content panels.
---

Tabs render a horizontal (or vertical) row of triggers. Use `tab-active` on the current item, `disabled` to deactivate one, and modifiers like `tabs-bordered` or `tabs-lifted` for different visual treatments.

## Bordered

Use `tabs-bordered` to add a baseline that highlights the active item.

## Lifted

`tabs-lifted` connects the active tab visually with its `tab-content` panel.

## Sizes

Use `tabs-xs`, `tabs-sm`, `tabs-md` (default), `tabs-lg` or `tabs-xl` to scale the row.

<HtmlPreview name="tab-sizes" />

## Vertical

Combine `tabs-vertical` with `tabs-bordered` for sidebar-style navigation.
