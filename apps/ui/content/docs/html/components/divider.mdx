Dividers separate content with a horizontal or vertical line. They support semantic colors, dashed/dotted styles and inline labels.

<DividerClassesTable />

## Default

The base divider only requires the `divider` class. Its text content becomes the centered label.

<HtmlPreview name="divider-default" />

## Colors

Apply semantic colors using `divider-primary`, `divider-secondary`, `divider-accent`, `divider-info`, `divider-success`, `divider-warning` or `divider-error`.

<HtmlPreview name="divider-colors" />

## Vertical Divider

Use `divider-horizontal` inside a flex row to render a vertical separator between siblings.

<HtmlPreview name="divider-vertical" />

## Styles

Combine `divider-dashed` or `divider-dotted` to change the line style.

<HtmlPreview name="divider-styles" />

## Placement

Use `divider-start` or `divider-end` to anchor the label to one side.

<HtmlPreview name="divider-placement" />
