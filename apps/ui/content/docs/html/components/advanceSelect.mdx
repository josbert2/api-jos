Advance select renders a custom searchable dropdown with rich options. The toggle, menu and options each have their own classes so they can be styled independently. Interactivity requires a small JS layer; the markup below shows the static structure.

<AdvanceSelectClassesTable />

## Default Advance Select

Use `.advance-select-toggle` for the trigger, `.advance-select-menu` for the dropdown, and `.advance-select-option` for each item.

<HtmlPreview name="advanceSelect-default" />

## Advance Select Sizes

Control the size using `advance-select-xs`, `advance-select-sm`, `advance-select-md` (default), `advance-select-lg`, or `advance-select-xl`.

<HtmlPreview name="advanceSelect-sizes" />

## Advance Select with Active Option

Use `select-active` on the currently selected `.advance-select-option`.

<HtmlPreview name="advanceSelect-active" />

## Advance Select Tag

Use `.advance-select-tag` to render the selection as a chip-style box.
