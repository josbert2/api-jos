File inputs let users upload files from their device. They reuse the `input` class with `type="file"` and inherit the same sizes and validation states.

<FileinputClassesTable />

## Default File Input

The base file input uses the `input` class on an `<input type="file">` element.

<HtmlPreview name="fileinput-default" />

## File Input Sizes

Control the size using `input-xs`, `input-sm`, `input-md` (default), `input-lg`, or `input-xl`.

<HtmlPreview name="fileinput-sizes" />

## File Input States

Use `is-valid` or `is-invalid` to color the file selector button accordingly.

<HtmlPreview name="fileinput-states" />

## File Input with Label

Combine the file input with a `label-text` and `helper-text` to give context.

<HtmlPreview name="fileinput-label" />

## Disabled File Input

Use the native `disabled` attribute to prevent file selection.
