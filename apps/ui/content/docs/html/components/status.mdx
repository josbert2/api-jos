A small dot to indicate state, presence, or availability. Status comes in semantic colors and five sizes.

<StatusClassesTable />

## Default Status

Use the `status` class on an inline element to render a neutral dot.

<HtmlPreview name="status-default" />

## Status Colors

Apply semantic colors using `status-primary`, `status-secondary`, `status-accent`, `status-info`, `status-success`, `status-warning`, or `status-error`.

<HtmlPreview name="status-colors" />

## Status Sizes

Control the size with `status-xs`, `status-sm`, `status-md` (default), `status-lg`, or `status-xl`.

<HtmlPreview name="status-sizes" />

## Status with Label

Pair a status dot with a label to communicate system state.

<HtmlPreview name="status-with-label" />

## Pulsing Status

Combine status with `animate-ping` to highlight a live state.
