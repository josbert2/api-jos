Style anchor elements with semantic colors and underline behaviors. The `link` class adds a default underline that you can customize with modifiers.

<LinkClassesTable />

## Default Link

Apply the `link` class to any `<a>` element.

<HtmlPreview name="link-default" />

## Link Colors

Use `link-primary`, `link-secondary`, `link-accent`, `link-info`, `link-success`, `link-warning`, or `link-error`.

<HtmlPreview name="link-colors" />

## Hover Underline

Use `link-hover` to hide the underline until the link is hovered.

<HtmlPreview name="link-hover" />

## Animated Underline

Use `link-animated` for a sliding underline that grows on hover.

<HtmlPreview name="link-animated" />

## Disabled Link

Add the `disabled` class (or `aria-disabled`) to render a non-interactive link.

<HtmlPreview name="link-disabled" />
