Switches toggle a single setting on or off. They support sizes, semantic colors, an outline variant, and disabled state.

<SwitchesClassesTable />

## Default Switch

The base switch only requires the `switch` class on an `<input type="checkbox">`.

<HtmlPreview name="switches-default" />

## Switch Sizes

Control the size using `switch-xs`, `switch-sm`, `switch-md` (default), `switch-lg`, or `switch-xl`.

<HtmlPreview name="switches-sizes" />

## Switch Colors

Apply semantic colors using `switch-primary`, `switch-secondary`, `switch-accent`, `switch-info`, `switch-success`, `switch-warning`, or `switch-error`.

<HtmlPreview name="switches-colors" />

## Outline Switch

Use `switch-outline` for a switch with a visible border instead of a solid background.

<HtmlPreview name="switches-outline" />

## Switch with Label

Wrap a switch and a `.label-text` inside a `<label>` to make the label clickable.

<HtmlPreview name="switches-label" />

## Disabled Switch

Use the native `disabled` attribute to indicate the switch cannot be toggled.

<HtmlPreview name="switches-disabled" />
