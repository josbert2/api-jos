Show contextual hints when hovering or focusing an element. Tooltips support semantic colors and any positioning around the trigger.

> The previews below force the tooltip visible so you can see the markup. In production, the `tooltip-content` element is hidden until the parent receives `:hover` or `:focus-visible`, typically via a small JS controller.

Wrap the trigger in `tooltip` and place the floating panel inside `tooltip-content` with a `tooltip-body` for the bubble.

## Tooltip Colors

Apply semantic colors using `tooltip-primary`, `tooltip-secondary`, `tooltip-accent`, `tooltip-info`, `tooltip-success`, `tooltip-warning`, or `tooltip-error` on the body.
