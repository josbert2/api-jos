Inputs let users enter text, numbers, dates, and other values. They support sizes, validation states, floating labels, and addons.

<InputClassesTable />

## Default Input

The base input only requires the `input` class on a wrapper or directly on the `<input>` element.

<HtmlPreview name="input-default" />

## Input Sizes

Control the input size using `input-xs`, `input-sm`, `input-md` (default), `input-lg`, or `input-xl`.

<HtmlPreview name="input-sizes" />

## Input States

Use `is-valid` or `is-invalid` to communicate validation status. Disable an input with the native `disabled` attribute.

<HtmlPreview name="input-states" />

## Input Types

The `input` class works with any HTML input type: text, email, number, password, date, etc.

<HtmlPreview name="input-types" />

## Floating Label

Wrap the input in `.input-floating` and add a `.input-floating-label` to get an animated label that floats on focus.

<HtmlPreview name="input-floating" />

## Input with Icon

Place an icon inside the input wrapper for visual context.
