Labels describe form controls and provide helper or status messages. Use `label-text` for the main label, `helper-text` for hints, and `success-message` / `error-message` for validation feedback.

<LabelClassesTable />

## Default Label

The base label uses the `label-text` class on a `<label>` element.

<HtmlPreview name="label-default" />

## Label with Input

Combine `label-text` with an input to label a form control.

<HtmlPreview name="label-input" />

## Helper Text

Use `helper-text` below an input to give the user extra context.

<HtmlPreview name="label-helper" />

## Validation Messages

Use `success-message` and `error-message` next to validated inputs. They show automatically inside a `.validate` container or when the input has `is-valid` / `is-invalid`.
