Selects let users pick a single value from a dropdown list. They support sizes, validation states, floating labels, and disabled state.

<SelectClassesTable />

## Default Select

The base select only requires the `select` class on a `<select>` element.

<HtmlPreview name="select-default" />

## Select Sizes

Control the size using `select-xs`, `select-sm`, `select-md` (default), `select-lg`, or `select-xl`.

<HtmlPreview name="select-sizes" />

## Select States

Use `is-valid` or `is-invalid` to communicate validation status. Disable a select with the native `disabled` attribute.

<HtmlPreview name="select-states" />

## Floating Label

Wrap the select in `.select-floating` and add a `.select-floating-label` to get a floating label.

<HtmlPreview name="select-floating" />

## Disabled Select

Use the native `disabled` attribute to indicate the select cannot be interacted with.

<HtmlPreview name="select-disabled" />
